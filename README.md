# 🎲 다이스 & 스파이어 (Dice & Spire)

> 주사위 덱빌딩 로그라이크 웹 게임 (Dice-building Roguelike Web Game)

---

## 📖 게임 소개
**다이스 & 스파이어(Dice & Spire)**는 주사위의 각 면을 강화하고 커스터마이징하여 던전의 탑을 정복해 나가는 턴제 덱빌딩 로그라이크 게임입니다.

- **주사위 덱빌딩 시스템**: 주사위의 6개 면을 공격, 방어, 힐, 특수 효과(독, 화염, 취약 등)로 커스터마이징 (중복 숫자 배치 지원)
- **소비 아이템 2칸 (타로 카드)**: 전투 중 즉시 발동하여 전황을 뒤흔드는 일회용 타로 카드 2장 보관 & 사용 시스템
- **다이내믹 전투**: 주사위를 굴려 나온 면들을 전략적으로 배치 및 활용하여 몬스터 격파
- **로그라이크 성장 요소**: 층을 오를 때마다 주사위 면 각인 및 타로 카드 보충
- **파티클 & 사운드 이펙트**: 몰입감을 높여주는 웹 오디오 및 캔버스 파티클 애니메이션

---

## 🕹️ 실행 방법

### 방법 1: 브라우저에서 바로 실행
별도의 빌드 과정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 열면 바로 플레이할 수 있습니다.

### 방법 2: 로컬 Node.js 서버로 실행
```bash
node server.js
```
실행 후 브라우저에서 `http://localhost:3000`으로 접속합니다.

---

## 🛠️ 기술 스택
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Audio & Visuals**: Web Audio API (합성 사운드), HTML5 Canvas Particles
- **Backend (선택사항)**: Node.js (간이 정적 서버)
